# Creative direction

**Audience:** prospective partners and investors viewing a pitch deck.

**Tone:** composed, luxurious, analytical, credible. Quiet confidence rather than trading hype.

**Palette:** near-black midnight indigo, ivory editorial typography, restrained champagne hairlines, original blue/purple Ripple identity. Source colors remain those of the app.

**Motion:** slow camera pushes, 650 ms dissolves, paced feature chapters, ample reading time. Seven scenes, no rapid cuts or simulated trading activity.

**Typography:** Georgia display headlines; Segoe UI supporting copy. Native app typography remains intact within the video captures.

**Music:** original quiet stereo pad and bell-like pluck score, soft attack/release, normalized to -23 LUFS target with restrained peaks. No voice-over.

**Image workflow:** built-in image generation/editing, four separate calls. The first generated graphic establishes the style reference for the next three. Input targets were visually inspected first. Final images were copied into the project without replacing original screenshots.

**Video workflow:** programmatic vector art for titles and backgrounds; FFmpeg scales and composites original capture pixels, animates camera pushes, dissolves chapters, and muxes music. The generated promotional mockups are separate deliverables and are not substituted for the original UI in the film.
